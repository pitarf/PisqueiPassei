# Fase 7, UX e acabamento

## Objetivo
Deixar o sistema consistente, claro e confortável para uso diário, inclusive em telas menores.

## Entregas
- [x] Navegação principal.
- [x] Estados básicos de carregamento.
- [x] Estados vazios em áreas principais.
- [x] Mensagens de erro nas principais operações.
- [x] Fluxos de estudo principais.

## Pendências
- [ ] Auditoria visual de todas as rotas.
- [ ] Teste mobile.
- [ ] Teste desktop.
- [ ] Teste de teclado nos fluxos principais.
- [ ] Revisão de contraste e legibilidade.
- [ ] Revisão de estados de carregamento.
- [ ] Revisão de estados vazios.
- [ ] Desabilitar ações enquanto gravações críticas estão em andamento.
- [ ] Confirmar feedback visual de acerto/erro.
- [ ] Confirmar mensagens de falha de IA e banco.

## Testes
- [ ] Abrir cada rota diretamente.
- [ ] Recarregar cada rota.
- [ ] Navegar para frente e voltar.
- [ ] Tela estreita.
- [ ] Tela larga.
- [ ] Falha de API.
- [ ] Falha de geração de IA.
- [ ] Banco indisponível.
- [ ] Ação repetida rapidamente.

## Critério de conclusão
Nenhuma ação importante deve parecer concluída quando ainda estiver sendo processada, e toda falha deve apresentar uma orientação compreensível ao usuário.
