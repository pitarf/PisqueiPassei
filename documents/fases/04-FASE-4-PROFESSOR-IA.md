# Fase 4, Professor IA

## Objetivo
Criar um professor contextualizado pelo edital, pelo RAG e pelo histórico real do aluno, mantendo rastreabilidade e limites claros para conteúdo jurídico.

## Entregas
- [x] Professor IA.
- [x] Contexto de domínio.
- [x] Pontos fracos.
- [x] Erros recentes.
- [x] RAG por consulta.
- [x] Histórico persistente controlado pelo servidor.
- [x] Instruções para diferenciar conteúdo oficial e complementar.
- [x] Instruções para não inventar legislação.

## Pendências
- [ ] Testar perguntas de todas as disciplinas.
- [ ] Testar perguntas jurídicas com fonte disponível.
- [ ] Testar perguntas jurídicas sem fonte suficiente.
- [ ] Testar pergunta fora do escopo.
- [ ] Confirmar persistência do histórico.
- [ ] Confirmar que contexto enviado pelo cliente não substitui dados persistidos.
- [ ] Validar respostas com amostra manual antes de liberar como material de estudo.
- [ ] Avaliar modelo Gemini atualmente configurado e sua disponibilidade antes de produção definitiva.

## Testes
- [ ] Explicação conceitual.
- [ ] Correção de questão.
- [ ] Comparação entre alternativas.
- [ ] Dúvida de Português.
- [ ] Dúvida de Matemática.
- [ ] Dúvida de Logística.
- [ ] Dúvida de Administração.
- [ ] Dúvida de Contabilidade/Informática.
- [ ] Dúvida sobre legislação.
- [ ] Pergunta fora do edital.
- [ ] Conversa com histórico longo.

## Critério de conclusão
O professor deve responder de forma útil e contextualizada, mas não pode transformar ausência de fonte em certeza, especialmente em matéria jurídica.
